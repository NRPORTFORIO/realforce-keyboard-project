# 📂 組み込みファームウェア開発 ポートフォリオ

C言語を用いた組み込み開発のコアアルゴリズム（入力制御およびセンサー処理）をシミュレートしたプロジェクトです。
ハードウェア依存部分を排除し、ロジックの正確性と省メモリ性を純粋にアピールする構成にしています。

---

## 🛠️ 実装した主要機能と技術的アピールポイント

### 1. チャタリング防止（デバウンス）処理 (`debounce.c`)
* **概要**: キーボードのスイッチや操作盤の物理ボタンで必ず発生する「電気的なノイズ（バタつき）」をソフトウェアで除去します。
* **こだわり**: 
  * 状態管理をC言語の`struct`（構造体）でカプセル化し、複数入力の並行処理に容易に拡張できる設計にしました。
  * タイマーや割り込み処理が限られた軽量なマイコン環境でも動作するよう、シンプルなカウンタ方式を採用しています。

### 2. 動性感度調整 ＆ ヒステリシス制御 (`sensor_control.c`)
* **概要**: 高級キーボードのAPC（感度調整）機能や、産業用機器の近接センサー制御を想定したアナログ値の判定処理です。
* **こだわり**:
  * 列挙型（`enum`）と配列を組み合わせ、動的なしきい値切り替え（高感度・標準・低感度）をO(1)の計算量で高速に処理します。
  * 値がしきい値付近で微小に変動した際にON/OFFが頻繁に切り替わるのを防ぐため、**ヒステリシス（不感帯）制御**を実装し、入力の安定性を担保しています。

---

## 📂 構成ファイル
* `debounce.c`: チャタリング防止アルゴリズムと検証用のメイン関数
* `sensor_control.c`: アナログ値判定・ヒステリシス制御アルゴリズムと検証用のメイン関数

---

## 📈 今後の拡張性（汎用的なロードマップ）
本リポジトリのロジックをベースに、以下のような実機（マイコン）環境や他分野への応用が可能です。
1. **工作機の操作盤対応**: 複数ボタンを同時にスキャンする「キーマトリクス駆動」への応用。
2. **通信連携**: USB HIDレポート形式へのデータ変換処理を追加し、PCやホスト機器へデータを安全に送信するモジュールの実装。
3. **省電力化**: マイコンの低消費電力モード（スリープ）と割り込みを組み合わせた電力最適化。
